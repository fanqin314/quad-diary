# 四象限日记 · QUAD DIARY

> 本地优先的四象限日记。点标签、写一句、加张照片，**十秒记完一天**。无账号、无云同步、无服务器。

**在线用** → https://fanqin314.github.io/quad-diary/
**装到手机** → 用 Chrome / Edge 打开上面的地址 → 菜单 →「添加到主屏幕」；Android 也可以装 `android/` 打出来的 APK。

---

## 这是什么

给自己一个人用的日记，不是待办清单，也不是时间管理工具。

> 目标不是「管理生活」，是让一个不做日记、记忆很差、晚上容易陷进短视频里的人，**能回头看、能有下一步、能收住今天**。

所以它只做三件事：

| 时刻 | 它做什么 |
| --- | --- |
| 想记的那一刻 | **今天卡**：四象限点一格、写一句、可选贴图 |
| 下课那一刻 | **课程条**：有课才出现，不占独立页面 |
| 周日晚上 | **回看**：周记 / 一年前 / 统计 / 备份 |

## 功能

- **今天卡**：四象限（重要且紧急 / 重要不紧急 / 紧急不重要 / 都不）点一格就记下；一句话 + 可选照片。
- **课程条**：从 `kcb-data.js` 读课表，当天有课才出现。
- **回看**：周记、一年前的今天、统计。
- **备份**：一键导出 zip（含照片），可再导入恢复 —— 换手机、清缓存前先导一次。
- **主题**：深 / 浅两套，跟随系统偏好。
- **离线**：Service Worker 缓存整个外壳，断网也能记。
- **Android 壳**：`android/`，WebView + 离线 assets，可打成 APK。

## 数据存在哪（重要）

- 文字：`localStorage`
- 照片：`IndexedDB`
- **没有账号、没有服务器、没有云同步。**你的日记不会离开这台设备。
- 代价是：**清浏览器数据 = 数据没了。** 请定期「导出备份」。
- 换设备：旧设备导出 zip → 新设备导入。

## 本地运行

```bash
node server.js        # → http://127.0.0.1:8080/index.html
```

Windows 上也可以直接双击 `打开日记.vbs`。

## 开发说明

- 整个应用是**单文件** `index.html`（约 6300 行，样式与脚本内联）。这样 PWA 缓存最简单、部署零构建。
- **改完必须手动把 `sw.js` 里的 `CACHE` 版本号 +1**（现在是 `quad-diary-shell-v33`），否则老用户永远拿到旧缓存。
- 设计取舍、历次改动、踩过的坑，都在 **[`功能计划.md`](功能计划.md)**（22 轮记录，包含"为什么没做某个功能"）。
- Android 壳：见 `android/README.md` 与 `android/VERIFY.md`。
